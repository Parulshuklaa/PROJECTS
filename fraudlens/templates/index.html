Architecture & honest limitations

Flask REST APIs + SQLite + vanilla JavaScript. Random forest learns labelled fraud patterns; a deep multilayer autoencoder reconstructs legitimate behaviour. Inputs are standardized using training data only. No automatic retraining from analyst feedback.

This is a synthetic-data prototype, not a banking product. Scores are not calibrated probabilities. Deployments need authentication, access control, monitoring, real-data evaluation, and temporal splits.

FraudLens / Explainable transaction intelligence · Built to investigate, not to make financial decisions.
